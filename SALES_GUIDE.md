## 🗣️ Objection Handling Scripts

### "Why not just use Wix/WordPress?"

**Response**:
> "Great question! Wix and WordPress are fine for getting started, but they have serious limitations:
> 
> **Performance**: They're bloated with features you don't need. Your site loads in 5+ seconds, which kills conversions. Google also ranks slow sites lower.
> 
> **Security**: WordPress powers 40% of the web, making it a huge target for hackers. You need constant updates and security plugins.
> 
> **Scalability**: If you go viral or run a successful ad campaign, these platforms can crash under load.
> 
> My solution gives you the ease of Wix but with the performance and security of enterprise software. Sites I build load in under 1 second and can handle millions of visitors."

## 📞 Discovery Call Questions

### Qualifying Questions
1. **What's your primary goal?**
   - Validate idea → Basic
   - Launch e-commerce → Intermediate
   - Scale existing business → Premium

2. **What's your current monthly revenue (if existing)?**
   - <$5k → Basic
   - $5k-50k → Intermediate
   - >$50k → Premium

3. **What's your timeline?**
   - ASAP → Basic
   - 1-2 months → Intermediate
   - 2-3 months → Premium

4. **What's your budget?**
   - <$1k → Basic
   - $1k-5k → Intermediate
   - >$5k → Premium

### Technical Questions
1. **Do you have an existing site?**
   - If yes: "What don't you like about it?"
   - Common answers: Slow, hard to update, looks dated

2. **Do you need e-commerce?**
   - If no → Basic
   - If yes → "How many products?" → Intermediate or Premium

3. **Do you need custom integrations?**
   - If yes → Premium

4. **How comfortable are you with technology?**
   - Low → Basic or Intermediate (managed solutions)
   - High → Premium (more control)
